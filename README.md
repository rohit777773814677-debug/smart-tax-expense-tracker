# Smart Tax & Business Expense Tracker

A modern expense management web application built using **React.js** and the **Context API**. It helps users track financial cash flow, categorize transactions (Office, Travel, Tools, Tax & Compliance), and compute ledger totals with automatic Indian Rupee (₹) formatting.

## Features
- **Real-Time Balance Calculation:** Instantly calculates total balance, overall income, and total expenses.
- **Business Expense Categories:** Classify items under Office Supplies, Travel, Software Tools, Client Meetings, and Tax & Compliance.
- **Global State Management:** State handled across components using React Context API and `useReducer`.
- **Responsive Layout:** Clean, minimalist financial ledger interface.

## Tech Stack
- React.js (Functional Components, Hooks: `useState`, `useContext`)
- React Context API
- CSS3
